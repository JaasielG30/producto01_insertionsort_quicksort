Benchmark: Shellsort vs Quicksort
Proyecto experimental para la Escuela Profesional de Ingeniería de Sistemas e Informática (ESIS) de la UNJBG.
Banco de pruebas en C++ para comparar el rendimiento de los algoritmos Shellsort y Quicksort. Evalúa vectores con diferentes patrones (aleatorios, ascendentes, descendentes, casi ordenados y con duplicados) en tamaños de 1,000, 10,000 y 100,000 elementos, midiendo tiempos, comparaciones, intercambios y profundidad de pila.
src/: Código fuente en C++ (algoritmos y experimentos).
include/: Archivos de cabecera.
resultados/: Archivo CSV con las mediciones.
documentos/: Artículo científico en Word (manuscrito.docx).
